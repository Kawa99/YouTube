# Data Dictionary

This document describes the research export files generated by `/export/research.zip` and `/export/research.jsonl`.

The authoritative export headers live in `export.py` under `RESEARCH_HEADERS`. The ZIP export also includes `manifest.json` and a generated `data_dictionary.md` with field types, source tables, data layers, and allowed labels.

Current schema version: `1.0.0`

## Export Semantics

- ZIP exports include `manifest.json` with `schema_version`, generated timestamp, active filters, filenames, and columns.
- CSV nulls are serialized as empty cells.
- JSONL rows include `dataset` and `schema_version` fields.
- JSONL exports start with a manifest row where `dataset` is `manifest`.
- Datetimes and dates are ISO formatted.
- JSON/list fields are serialized as JSON strings in CSV.
- Public competitor data and private owned-channel analytics are separate datasets.
- Owned analytics fields must only be used for channels the operator owns or is authorized to access.

## Dataset Headers

### `channels.csv`

Channel-level normalized public metadata plus channel labels.

Fields:

`channel_id`, `youtube_channel_id`, `channel_username`, `channel_name`, `handle`, `canonical_url`, `subscriber_count`, `view_count`, `video_count`, `country`, `default_language`, `published_at`, `last_collected_at`, `primary_niche`, `primary_format`, `faceless_status`, `sponsor_fit`, `policy_risk`, `production_complexity`, `reviewer`, `reviewed_at`, `notes`

### `videos.csv`

Video-level normalized public metadata plus video labels.

Fields:

`video_id`, `youtube_video_id`, `youtube_channel_id`, `channel_username`, `channel_name`, `title`, `description_excerpt`, `published_at`, `duration_seconds`, `category_id`, `default_language`, `caption_available`, `thumbnail_url`, `thumbnail_quality`, `thumbnail_cached_path`, `thumbnail_phash`, `transcript_status`, `views`, `likes`, `comments`, `last_collected_at`, `niche`, `format`, `faceless_status`, `visual_style`, `packaging_pattern`, `title_pattern`, `thumbnail_pattern`, `viewer_promise`, `curiosity_type`, `clarity_score`, `specificity_score`, `honesty_score`, `visual_readability_score`, `differentiation_score`, `topic_type`, `production_complexity`, `policy_risk`, `review_status`, `label_confidence`

### `manual_labels.csv`

Unified video/channel human labels for analysis.

Fields:

`entity_type`, `entity_id`, `youtube_id`, `display_name`, `channel_username`, `niche`, `format`, `faceless_status`, `ai_use_visible`, `visual_style`, `packaging_pattern`, `title_pattern`, `thumbnail_pattern`, `viewer_promise`, `curiosity_type`, `clarity_score`, `specificity_score`, `honesty_score`, `visual_readability_score`, `differentiation_score`, `topic_type`, `production_complexity`, `policy_risk`, `monetization_signals`, `sponsor_fit`, `reviewer`, `review_status`, `reviewed_at`, `label_confidence`, `notes`

### `snapshots.csv`

Append-only public metric snapshots for videos and channels.

Fields:

`entity_type`, `snapshot_id`, `entity_id`, `youtube_id`, `display_name`, `channel_username`, `snapshot_at`, `view_count`, `like_count`, `comment_count`, `subscriber_count`, `video_count`, `collection_run_id`

### `derived_metrics.csv`

Repeatable computed metrics for opportunity analysis.

`id`, `video_id`, `youtube_video_id`, `title`, `channel_username`, `youtube_channel_id`, `snapshot_at`, `age_days`, `views_per_day`, `views_per_subscriber`, `channel_recent_median_views`, `relative_performance`, `duration_bucket`, `performance_tier`, `outlier_flag`, `like_rate`, `comment_rate`, `engagement_rate`, `computed_at`, `algorithm_version`

### `collection_runs.csv`

Collection-job lineage, quota estimates, and error summaries.

Fields:

`id`, `run_type`, `status`, `input_type`, `input_value`, `requested_limit`, `started_at`, `completed_at`, `quota_estimate`, `items_found`, `items_saved`, `items_failed`, `error_summary`, `created_by`

### `content_theses.csv`

`id`, `thesis_id`, `title`, `target_viewer`, `viewer_promise`, `format`, `topic_universe`, `production_edge`, `packaging_edge`, `monetization_path`, `policy_risk_argument`, `status`, `notes`, `created_at`, `updated_at`

Fields:

`id`, `thesis_id`, `thesis_code`, `evidence_type`, `channel_id`, `channel_username`, `video_id`, `youtube_video_id`, `source_url`, `note`, `confidence`, `created_at`

## High-Value Fields

- `youtube_video_id`, `youtube_channel_id`: stable YouTube identifiers.
- `collection_run_id`: lineage back to a collection run.
- `snapshot_at`: when public metrics were observed.
- `relative_performance`: views versus recent channel baseline.
- `outlier_flag`: boolean outlier marker.
- `label_confidence`: reviewer confidence, not model confidence.
- `policy_risk`: monetization or platform-risk judgment.
- `token_secret_ref`: pointer to external secret storage.

## Controlled Labels

Allowed values are enforced in the UI/service layer for many fields. The generated `data_dictionary.md` inside each research ZIP contains the latest allowed-label strings.
